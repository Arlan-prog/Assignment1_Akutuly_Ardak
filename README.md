# Student Management System

Учебный Java-проект для работы со студентами и курсом: хранит GPA и кредиты, находит лучшего студента и считает средний GPA курса.

## Запуск

Нужна Java 11 или новее. Из корня проекта:

```sh
javac src/*.java
java -cp src Main
```

GPA ограничен диапазоном от 0.0 до 4.0; число кредитов и вместимость курса не могут быть отрицательными.
